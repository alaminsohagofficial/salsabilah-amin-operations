# Salsabilah Amin Operations

Central management repository for **Salsabilah Electronics** and **S.R. Electronics Park**. This hub automates business workflow tracking, financial reconciliation, multi-showroom stock logistics, and ERP integrations.

## Repository Purpose

* **Audit & Financial Reconciliation:** Automated tracking of banking advisories (DBBL/NPBS), ledger clearance documents, and settlement reports.
* **Regional Logistics:** Operations and stock monitoring for showrooms in Chuadanga, Kushtia, and Meherpur.
* **ERP & System Integration:** Synchronizing internal e-commerce data with enterprise systems.
